## Warehouse model and baselines
The learned embedding and positional vectors distinguish hour, weekday and lag.
The last-position attention output drives a small tanh MLP. There is no residual,
LayerNorm, oracle flag, or hidden preprocessing fitted on held-out data. Training
uses standardized MSE and checkpoints by validation MAE. Test windows are identical
for attention, last value, moving average, seasonal naive and ridge. A learned
pooling query and unscaled attention are secondary controlled comparisons.

## Shift attribution
Paired generator streams preserve noise/drop draws across spike interventions.
The base scaler and trained weights are frozen. Noise, spike magnitude and rate are
varied separately and together. Baselines use the same target hours. Larger demand
can leave the training input range (`outside_train_range` in the JSON), increasing
similarity magnitudes through the bilinear projections. This is a plausible
mechanism, not proof that saturation alone caused forecast degradation.

Sources, in table order: `results/gradcheck.json`, `numerical_stability.json`,
`toy_task.json`, `training_dynamics.json`, `lora_adaptation.json`, `jax_compare.json`,
`paper_reproduction.json`.

Central differences use a scalar squared-output loss and perturb every element of
X and each projection. Max absolute differences and the complete analytical and
numerical vectors accompany relative errors. Float32 loses meaningful differences
at small epsilon sooner than float64. See `gradcheck_eps_sweep.png`; the tradeoff is
truncation versus subtractive round-off, not evidence of an exact symbolic result.

Max subtraction prevents exponential overflow but cannot prevent a sharply peaked
probability row. The stability experiment fixes upstream value coefficients so the
reported logit-gradient collapse is not confounded by a trained head. Fully masked
rows are explicitly zero; +inf and NaN inputs raise an error. Float16, float32 and
float64 output errors against the same float64 reference are saved in the JSON.

The toy mean-pool control is linear after mean pooling: it cannot bind each key to
its associated value. It can exploit the value histogram, so chance is not its
best possible accuracy. Toy attention must retrieve the bound record. The heatmap
and matching-key mass complement accuracy; good warehouse performance alone would
not prove that the attention mechanism learned selective retrieval.

The dynamics grid isolates learning rate and Q/K initialization. Scaling both Q/K
initialization by c multiplies similarities by c squared. The softmax Jacobian
then contracts as rows saturate; the initial entropy/gradient columns and full
per-step traces test this mechanism. Any final plateau must be assessed against the
actual validation curve; a large learning rate may also recover or destabilize
training. Plot: `results/training_dynamics.png`.

LoRA freezes all original parameters and adds zero-initialized B times random A
to Q and V only. This preserves the original function at initialization; K and
the forecast head remain fixed. Full fine-tuning and LoRA see the same early shifted
slice, epochs, optimizer rate and later validation block. No adaptation sees no
training slice. Test targets are disjoint from both adaptation and validation.

JAX uses pure functions and explicit PRNG keys; PyTorch modules hold parameters and
use a seeded global RNG. Float64 is enabled explicitly in JAX; the comparison
copies identical arrays, checks all input/weight gradients and tests JIT outputs.
It does not benchmark JAX compilation or claim cross-framework training equivalence.

Profiling uses CPU allocation timeline events for additional live tensor high-water
memory, excludes preexisting input storage and process/library RSS, and reports
retained tensor storage separately. `results/profiling.json` contains timings and
naive/stable softmax costs. Small sequences include Python/validation overhead;
the quadratic attention matrices predict asymptotic memory growth, not exact
quadratic wall time at all sizes. Timings are deliberately excluded from the
deterministic summary. Temperature and matrix-rank measurements are in
`numerical_stability.json`, with `temperature.png`.

The paper experiment reproduces only the independent dot-product variance argument
from [Vaswani et al., section 3.2.1](https://arxiv.org/html/1706.03762#S3.SS2.SSS1).
It is not a reproduction of translation training or reported model quality.

## Cross-problem integration and interpretation limits
Both problems import `src/wdam/attention/core.py`. Toy records require selective
retrieval; warehouse forecasting requires calendar-conditioned lag information.
Compare toy matching mass (`toy_task.json`) with lag mass (`attention_viz.json`)
and H3's recorded decision above. A failed H3 means the expected concentration was
not demonstrated even if forecasts improve. Learned value projections and the
head can extract useful information from diffuse weights.

Attention weights are not causal explanations. The input perturbation in
[FAILURE_ANALYSIS.md](FAILURE_ANALYSIS.md) changes both projected values and weights;
its prediction delta measures model sensitivity, not a unique attribution or a
real-world causal effect. No optional forecasting fix was run; suggestions there
are future experiments, not claimed improvements.
